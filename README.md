# BIOS Collective · 交互原型

静态前端演示。九组协作、Oasis 独立建议、员工私人推敲、记忆与经验、Competence 目录。

## 在线体验
https://bestfridayai-lab.github.io/bios-collective-prototype/

## 本地打开
下载 `index.html` 后用浏览器打开。图片、字体、样式与脚本均已内嵌，无需安装或启动服务器。

所有业务数据、员工发言、决策和 AI 回复均为虚构模拟。输入仅保存在当前浏览器中；没有真实登录、模型推理或多人同步。此仓库不包含本机聊天和上传资料。

## GitHub Pages 配置
Settings → Pages → Deploy from a branch → main / (root)。
